title: Linux
---

Latest version is always recommended.

{{% steps %}}

### Download from [Github Releases](https://github.com/f1shl3gs/vertex/releases) 
```shell
wget https://github.com/f1shl3gs/vertex/releases/download/v0.1.0/vertex_x64_linux_gnu.tar.gz
```

### Decompress
```shell
tar -xvzf vertex_x64_linux_gnu.tar.gz 
```

### Add execute permission
```shell
chmod +x vertex_x64_linux_gnu/vertex
```

### Check 
```shell
./vertex_x64_linux_gnu/vertex -v
```

{{% /steps %}}
