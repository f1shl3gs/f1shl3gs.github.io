## data_dir
The directory used for persisting Vertex state data.

## timezone
The name of the timezone to apply to timestamp conversions that do not contain
an explicit timezone.

The timezone name may be any name in the [tzdb](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones), or `local` to indicate system
local time.

## proxy
Configure to proxy traffic through an HTTP(s) proxy when making external requests.
